# 📋 Workshop Agenda — Framework IA Contoso × Stack Microsoft

### Workshop App — itens consumidos pela sidebar dinâmica

- Mapeamento Requisitos Contoso × Stack Microsoft: Tabela filtrável dos 24 requisitos do Framework IA Contoso e como cada produto Microsoft endereça cada um
- Visão Geral da Stack & Arquitetura Integrada: Pilares Contoso, ciclo dev/operações e componentes da stack Microsoft (Foundry, Agent 365, APIM, Entra, Purview)
- Estrutura de Projetos do Foundry: Ambiente de teste com paridade de produção, inventário, RBAC, auditoria e segregação de ambientes
- Criação Simplificada de Agente: Foundry Playgrounds, VS Code extension e declarative agent workflows para sair de uma descrição de alto nível para um agente funcional
- Hosted Agents: Foundry Hosted Agents como runtime gerenciado — endpoint estável, identidade no Entra, threads e tools nativas, sem operar infraestrutura
- Prompt como Ativo Versionado: Prompty, Foundry Projects e Agent Development Lifecycle para versionar, auditar e revisar prompts
- LLM Arena & Comparação de Modelos: Catálogo de modelos do Foundry e comparação objetiva qualidade × custo × latência
- RAG com Foundry IQ: Agente conectado a base de conhecimento corporativa com chat ao vivo, grounding via Foundry IQ e evaluation com métricas RAG
- Multi-Agentes com MAF e Foundry Workflows: Padrões de orquestração do Microsoft Agent Framework (sequential, concurrent, handoff, group chat, magentic) e Foundry Workflows declarativos
- Modelagem e Fine-tuning: SLMs, destilação, fine-tuning, RLHF e DPO no Foundry Models com comparação interativa entre modelo base e modelo especializado
- Custom Evaluators & Scorecard Modular: Knowledge / Reasoning / Conversational, Custom Evaluators e índice único de maturidade
- Persona Sintética, Prompt Injection & Red Teaming: Risk & Safety Evaluators, simulators e AI Red Teaming via PyRIT
- CI/CD de Avaliações com Evidência Auditável: Evaluation runs em GitHub Actions e Azure DevOps gerando evidência para o pilar de governança
- Observabilidade em Produção: Agent Monitoring Dashboard, Optimization Dashboard com Ask AI, traces OpenTelemetry e dashboard customizado com métricas do AI Gateway via Log Analytics
- Governança Corporativa, Guardrails e Control Plane: Foundry Control Plane, Guardrails, Entra e Custom Azure Policy
- Agent 365 e Purview: Inventário corporativo de agentes, DLP e compliance regulatório
- Classificação de Risco: Critérios parametrizáveis, alinhamento ao PL 2338 e Custom Azure Policy for Foundry para enforcement de risco
- Integração com Agentes Externos (A2A): APIM AI Gateway, semantic caching, A2A multi-agent e MCP Tools
